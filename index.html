Panduan Penggunaan
Peta Relasi dan Riwayat Hukum Perdirjen DJPb
Navigasi Peta
  • Geser (Pan): Tahan tombol kiri mouse lalu seret untuk memindahkan pandangan ke seluruh penjuru peta jaringan.
  • Perbesar / Perkecil (Zoom): Gunakan tombol dan di toolbar peta, atau putar roda mouse di atas kanvas.
  • Fit ke Layar: Klik tombol untuk menyesuaikan semua node agar muat di layar sekaligus.
Interaksi dengan Node
  • Klik sekali pada sebuah titik/node di peta untuk menampilkan detail lengkap peraturan tersebut di Panel Detail sebelah kanan, termasuk identitas, relasi, dan riwayat perubahan.
  • Klik Ganda (Double Click) pada node mana pun untuk menambahkannya sebagai Ego Baru di peta — node tersebut beserta seluruh jaringannya akan ditampilkan sekaligus (Multi-Ego Union).
  • Kluster Biru menandai sekumpulan Dasar Hukum yang dikompresi. Klik Ganda pada kluster biru untuk membuka dan menampilkan semua node di dalamnya.
  • Cross-Highlighting: Saat kursor diarahkan ke baris Riwayat Perubahan atau chip Relasi di Panel Detail, node yang bersangkutan di kanvas akan menyala warna emas — memudahkan identifikasi posisinya di peta.
Pencarian & Referensi
  • Kotak Pencarian: Ketik nomor Perdirjen (misal: PER-1/PB/2024) di kotak pencarian. Dropdown otomatis muncul menampilkan daftar cocok — klik item atau tekan Enter untuk memuat peta.
  • Filter Tahun: Gunakan dropdown tahun di sebelah kiri kotak pencarian untuk mempersempit daftar autocomplete hanya ke tahun yang diinginkan.
  • Referensi Peraturan di toolbar: buka katalog seluruh Perdirjen, lengkap dengan filter tahun. Klik baris mana pun di katalog untuk langsung membuka petanya.
Panel Detail (Kanan)
  • Identitas Dokumen: Menampilkan tipe, status, nomor, tahun, tanggal, instansi, dan judul peraturan yang sedang dipilih.
  • Relasi Terhubung: Menampilkan chip-chip peraturan yang menjadi Dasar Hukum (diklik → buka peta baru) dan peraturan yang Diubah/Dicabut. Arahkan kursor ke chip untuk menyalakan node di kanvas (Cross-Highlighting).
  • Riwayat Perubahan: Tabel riwayat lengkap lintas relasi (kecuali Mengingat). Hover baris untuk menyalakan node bersangkutan, klik baris untuk membuka petanya.
  • Fokus di Peta : Pusatkan pandangan kanvas ke node terakhir yang dipilih dengan zoom yang diperbesar.
  • Salin Detail Peraturan : Salin seluruh detail (identitas, relasi, riwayat) sebagai teks terformat ke clipboard.
Pengaturan & Alat
  • Pengaturan : Buka panel pengaturan tampilan. Tersedia tiga sakelar — Mode Gelap untuk tema dark, Bekukan Jaringan untuk menghentikan animasi fisika, dan Sembunyikan Label Garis untuk menyembunyikan teks di atas relasi.
  • Muat Data : Muat ulang data dari file CSV dan reset seluruh tampilan ke kondisi awal. Gunakan jika data di file sumber diperbarui.
  • Toggle Sakelar Legenda Relasi: Di kotak Legenda (pojok kiri bawah peta), setiap jenis relasi memiliki sakelar sendiri. Matikan sakelar untuk menyembunyikan semua garis dan node eksklusif bertipe relasi tersebut dari kanvas secara instan.
